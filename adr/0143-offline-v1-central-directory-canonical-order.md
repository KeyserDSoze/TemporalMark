The current seekable in-memory .NET ZIP producer creates `manifest.json` then TSR members in canonical `(IssuedUtc, Id)` order; its ZIP central directory also lists entries in **creation order**. ADR 0141 added an offline check of the **physical local-header** order, using `sorted(zipped.infolist(), key=lambda item: item.header_offset)` and requiring the list to equal manifest-first plus exactly each TSR name in manifest order. However, the verifier separately computes `names = [item.filename for item in zipped.infolist()]` **from the central directory** and only requires unique names plus `set(names) == expected`. A ZIP can have unchanged local layout, manifest/TSR bytes, UTC/UUID order, DER hashes, local-vs-central CRC/method/flags, EOCD directory offset and compressed/uncompressed budgets, while entire **central-directory entry records** are reordered. A small independent Python stdlib test constructed precisely such a ZIP: `zipfile.ZipFile.read` still returned every original file and `ZipInfo.header_offset` still pointed at the original physical locations after swapping the central records. This is a genuine alternate ZIP representation absent from the current v1 writer, not proof of forged legal evidence.

## Rejected alternatives / explicitly unsupported claims

- Ignore central-order differences because generic ZIP readers permit them: a general-purpose parser must support many conforming ZIPs, but this intentionally narrow **current v1 exporter compatibility profile** has a fixed deterministic layout; accepting extra representations undermines reproducibility.
- Reorder central records to repair an archive: refused. A validator must not mutate evidence or hide a source discrepancy; reject and investigate.
- Infer cryptographic authenticity or legally enforceable timestamp order from ZIP entry order: **false**. The manifest and DER are not independently signed/witnessed here, privileged actors can coherently replace both, and the real historical QTSP signer/CMS policy/imprint/revocation, EU Trusted List, immutable WORM custody, complete-period signed high-water and CAB/AgID/eIDAS legal launch gate remain unresolved.
